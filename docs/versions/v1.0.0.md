# v1.0.0 — Fundação visual

- **Data:** 2026-11-23
- **Etapa:** 01 — Criação do projeto e fundação visual
- **Tipo:** versão inicial

## Escopo

Fundação visual e estrutural do painel administrativo, responsiva e preparada para receber os
módulos reais. Nenhum dado é armazenado: todas as listas estão vazias e todos os indicadores
mostram "Sem dados conectados".

## Páginas criadas

| Rota | Tela | Conteúdo inicial |
| ---- | ---- | ---------------- |
| `/` | Dashboard | Atalhos (pedido, cliente, produto), próximo ciclo e próxima entrega como "Não configurado", indicadores vazios, acesso aos módulos |
| `/pedidos` | Pedidos | Filtros, tabela vazia, etapas do pedido, novo pedido (pré-visualização) |
| `/clientes` | Clientes | Busca, tabela vazia, cadastro (pré-visualização), acesso por telefone + código (previsto) |
| `/produtos` | Produtos e estoque | Abas Produtos/Estoque, filtro por categoria, cadastro (pré-visualização) |
| `/separacao` | Separação de pedidos | Lista consolidada vazia e colunas por etapa |
| `/entregas` | Entregas e GPS | Próxima entrega não configurada, GPS em desenvolvimento, roteiro vazio |
| `/financeiro` | Financeiro e caixa | Indicadores por forma de pagamento vazios, movimentações vazias |
| `/relatorios` | Relatórios | Catálogo de relatórios previstos |
| `/whatsapp` | WhatsApp e notificações | Status "Não conectado", notificações previstas (desabilitadas) |
| `/usuarios` | Usuários e permissões | Tabela vazia, tipos de acesso (administrador e cliente) |
| `/calendario` | Calendário de vendas | Modelo semanal (seg. abertura → sex. encerramento → sáb. entrega), nenhum ciclo configurado |
| `/configuracoes` | Configurações | Dados do negócio e ciclo (desabilitados), pagamentos aceitos, região e versão |

## Componentes reutilizáveis

`src/components/shared/`: `PageHeader`, `SectionCard`, `EmptyState`, `StatCard`, `DataTable`
(tabela no desktop, cartões no celular), `FilterBar`, `FormField`, `PreviewFormDialog`,
`ConfirmDialog`, `StatusBadge`, `DevBadge`, `PendingButton`, `ModulePlan`.
`src/components/forms/`: diálogos de pedido, cliente e produto.
`src/components/layout/`: `AppShell`, `AppSidebar`, `AppHeader`, `MobileNav`.

## Decisões

- **Fonte única de módulos** (`src/lib/modules.ts`): menu, cabeçalho, metadados e testes usam a
  mesma lista, evitando divergência entre navegação e rotas.
- **Vocabulário de status** (`src/lib/domain/status.ts`) definido agora para servir de base aos
  enums do banco na v1.1.0.
- **Ações não implementadas** ficam sempre desabilitadas com o selo "Em breve" ou
  "Em desenvolvimento". Formulários abrem como pré-visualização com aviso de que não salvam.
- **Celular primeiro:** barra de navegação inferior (Início, Pedidos, Separação, Entregas, Menu),
  campos e botões com 44px de altura no toque, tabelas convertidas em cartões.
- **Padrões regionais fixos:** pt-BR, BRL e America/Sao_Paulo centralizados em `src/lib/format.ts`.
- **Tipografia:** Bricolage Grotesque (títulos) e Figtree (texto).
- Unidades de venda do formulário de produto (unidade, maço, kg, bandeja) são **sugestões
  provisórias**, a confirmar.
- Nenhuma dependência nova foi adicionada.

## Não implementado nesta versão

- Banco de dados, schema e regras de acesso (RLS).
- Autenticação do administrador e acesso do cliente por telefone + código.
- Salvamento de pedidos, clientes, produtos e configurações.
- Ciclo de vendas real (datas, horário de encerramento) e cálculo da próxima entrega.
- Indicadores, relatórios e exportações.
- Caixa, recebimentos e fechamento.
- WhatsApp, notificações, GPS e mapas.
- Checkout e loja do cliente.
- Conexão com GitHub (o projeto está apenas preparado).
